## 1. Descripción del Proyecto

Este proyecto explora las capacidades de GitHub Copilot como asistente de programación basado en Inteligencia Artificial, mediante la creación y documentación de un sistema de recomendación sencillo en Python.

## 2. Pasos Realizados

1. **Configuración Inicial:** Se creó el repositorio remoto `AI_PROYECT-BARBARA` en GitHub.
2. **Clonación Local:** Se clonó el proyecto mediante la terminal integrada de VS Code.
3. **Desarrollo del Código:** Se generó el script `recommendation_system.py` implementando un modelo de clasificación con KNN.
4. **Sincronización:** Se enviaron los cambios al repositorio remoto mediante *commit* y *push*.
